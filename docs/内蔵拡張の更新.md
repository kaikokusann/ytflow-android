# 内蔵拡張の更新

## LiveChat Flusher

- 上流: https://github.com/ys-j/YoutubeLiveChatFlusher
- 取り込み元: 正式リリース `v0.16.7`、コミット `17dcc4c08825bf308ea2cc52e76762db13f6e5e5`
- Firefox用Manifest V3を使用。拡張IDは既存の `youtube-live-chat-flusher@local` を維持する。
- 上流のライセンスは同フォルダの `LICENSE` に保持する。

Android側の独自差分は、設定画面、アプリからの弾幕設定変更、拡張のオン・オフ、通常チャット表示の連携に限定する。

通常チャットの表示は `normal_chat_view.mjs`、取得と表示間隔の制御は `normal_chat_page.mjs` に分離している。チャット専用ページではこの取得経路だけを使用し、YouTubeのフレームイベントを重ねて購読しない。アーカイブ開始位置・認証指定は新版の取得関数への追加オプションで渡す。旧版の初期化やMac用Popup実験は復元しない。

設定保存では拡張自体を再起動しない。保存成功をURLの `#ytchat-saved-...` でアプリへ通知し、設定を閉じる時点でYouTubeだけを再読み込みする。翻訳のバックグラウンド処理はストレージ変更を購読して設定を更新する。

## YT Chat Cleaner

上流機能は更新せず、設定ページの文字・操作領域・明暗表示を修正した。内蔵版の更新識別用にバージョンを `0.6.12.1` とする。

## 検証

設定画面の回帰テスト:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node tests/extension-settings.mjs
```

360px・740px・920px幅、明暗表示、回転、保存状態、旧設定の移行、通常チャットの絵文字・アイコン・名前、アーカイブ開始位置を検証する。必要なら `SCREENSHOT_DIR` に一時画像の保存先を指定できる。

加えて上流タグのテストを、`src` が内蔵拡張フォルダを参照する一時環境で実行する。上流のフレーム用モックには実ブラウザと同じ空の `location.hash` と `location.search` を追加する。

実機では、拡張の起動、両設定ページ、保存後だけの再読み込み、回転、弾幕と通常チャット、Android標準PiPを別途確認する。

### 今回の確認結果

- 上流テスト104件と追加回帰テスト14シナリオが成功。
- Android実機でManifest V3のバックグラウンド起動と弾幕表示を確認。
- 両設定画面の18px表示、24px操作部品、閉じるアイコン、縦横回転での未保存状態維持を確認。
- 保存なしで閉じたときは動画ページの `performance.timeOrigin` が維持され、保存後は再読み込みされることを確認。
- アーカイブ・ライブ双方の通常チャット表示と、背面動画への再生操作を確認。チャット専用モードの出入りで動画ページは再読み込みされない。
- YTFlowのActivityがAndroidのpinnedモードへ移行し、PiPが表示されることを確認。
